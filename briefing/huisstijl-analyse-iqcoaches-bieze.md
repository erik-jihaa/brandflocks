## iQ Coaches (iqcoaches.nl)

**Lettertype**

Geen custom webfont — systeemstack: `"Helvetica Neue", Helvetica, Arial, sans-serif`. Zowel koppen als lopende tekst gebruiken dezelfde stack.

**Hex-kleuren** (op gebruiksfrequentie)

| Hex | Rol op de site |
| --- | --- |
| `#0C1125` | Dominante kleur — hoofdtekst / donkere vlakken |
| `#F7F9FB` | Lichte achtergrond |
| `#FFFFFF` | Wit |
| `#4F5569` | Gedempt blauwgrijs — subtekst |
| `#0D0A46` | Diep indigo — secundaire donkere vlakken |
| `#747A96` | Lichter blauwgrijs |
| `#980028` | Bordeauxrood — accentkleur |
| `#5A80B9` | Blauw — linkkleur |
| `#D6DAE5` | Lichtgrijs — randen/vlakken |
| `#8D9598` | Grijs |

## Bieze (bieze.nl)

**Lettertypes**

- `Apertura` (fallback: arial, sans-serif) — lopende tekst → **poster v1: DM Sans** (Google Fonts)
- `"All of me"` (fallback: arial, sans-serif) — koppen (H1/H2), script/display — **niet op poster**

**Hex-kleuren** (op gebruiksfrequentie)

| Hex | Rol op de site |
| --- | --- |
| `#16281B` | Dominante donkergroene kleur — ook tekstkleur van koppen |
| `#C9D200` | Limoen/geelgroen — **poster-accentkleur** (besluit Erik) |
| `#007A37` | Merkgroen — secundair accent |
| `#FFFFFF` | Wit — poster-achtergrond |
| `#222222` | Bijna-zwart |

| `#999999` | Grijs |
| `#545454` | Donkergrijs |
